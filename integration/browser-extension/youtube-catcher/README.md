# AB Download Manager - YouTube Video Catcher Extension

Ekstensi pelengkap (*companion extension*) untuk **AB Download Manager** yang menambahkan tombol melayang (*floating catcher*) **"Download with AB Download Manager"** tepat di atas pemutar video YouTube layaknya **Internet Download Manager (IDM)**.

---

### Cara Memasang di Browser (Chrome, Edge, Brave, Opera):
1. Buka halaman ekstensi di browser Anda:
   - **Chrome**: ketik `chrome://extensions/` di address bar
   - **Edge**: ketik `edge://extensions/` di address bar
   - **Brave**: ketik `brave://extensions/` di address bar
2. Aktifkan sakelar **Developer mode** (Mode Pengembang) di pojok kanan atas.
3. Klik tombol **"Load unpacked"** (Muat ekstensi yang belum dibongkar).
4. Pilih folder ini:
   ```
   D:\Project\Antigravity\ab-download-manager\integration\browser-extension\youtube-catcher
   ```
5. Selesai! Buka video YouTube apa saja, dan tombol melayang **"Download with AB Download Manager"** akan otomatis muncul di atas video player.
